# ZIM Enterprise Retail POS
### The Retail Operating System Built for Zimbabwe

> Built for OK Zimbabwe, TM Pick n Pay, Spar, Enchanter - and every supermarket losing money to stock theft & old systems.

**Problem:** Big retail in Zim uses 20-year-old systems (Arch, SAP) that cost $100k+, don't support ZiG/USD dual pricing, EcoCash, or ZIMRA FDMS properly.

**Solution:** A modern, offline-first, enterprise POS that works when TelOne is down and reports to HQ live when it's back.

### 🚀 Enterprise Features (Roadmap)
- [x] Multi-branch live sync (HQ Dashboard)
- [ ] Barcode + Weighing Scale + Thermal Printer support
- [ ] Promotions Engine (Buy X Get Y, Branch-specific pricing)
- [ ] Cashier anti-theft tracking + manager approvals
- [ ] ZIMRA FDMS Fiscalization + Multi-currency (USD/ZiG)
- [ ] Works 100% offline, syncs later
- [ ] EcoCash, ZiG, USD payment integration

### 🛠️ Tech Stack (Free tier)
Frontend: Flutter (Tills) + React (HQ Dashboard)
Backend: Supabase / PostgreSQL
Hardware: Epson, Bixolon, Zebra scanners
